## Overview
This repository houses the code used to run experiments and reproduce the evaluation and figures in the paper. The repository is organized into two main components. Each component includes its own .md file documenting the hardware specifications and compute times. 

### 1. [Embbedding extraction](./embedding_extraction/)
This module provides a demonstration using the bilingual LLM EXAONE-3.5-7.8B, one of the models evaluated in the paper. The code can be adapted to other language models by modifying the model loading and embedding extraction components as needed (indicated in the code comments).
- Downloading the model: `download_model_exaone_3.5_7.8b.py` 
- Getting the embeddings of gap words and storing them in a dictionary format: `gap_embed_exaone_3.5_7.8b.py`
- Getting the embeddings of non-gap words and storing them in a dictionary format: `non-gap_embed_exaone_3.5_7.8b.py`
The directory also contains example embedding dictionaries generated by these scripts, illustrating the expected output format used in the downstream experiments.

3## 2. [Experiments and evaluation](./experiment_pipeline/)
- Processing the embedding dictionaries into dataframes for the experiment pipeline: `df_creation.py`
- Configurations and parameter settings for experiment runs: `config.py`
- Experiment pipeline (lexical gap detection): `pipeline.py`
- Evaluation, analysis, and visualization: `analysis.ipynb`

Plese refer to the paper for detailed experiment and evaluation procedures.
