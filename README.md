# Discovering Lexical Gaps Using Embeddings from Multilingual LLMs

### Yoonwon Jung, Aaron S. Cohen, Benjamin K. Bergen

Department of Cognitive Science, University of California San Diego

--

#### This repository houses the code used to:
- Filter a list of translations and gap words for analysis
- Grab embedding vectors from a Bilingual LLM and store in dictionary format
- Create translation and non-translation dataframes for use in experiment pipeline
- Select experiment parameters and embedding space transformation configurations
- Run experiments to calculate CSLS metrics for gap and non-gap words
- Analyze results using AUC and p@1
- Build logistic regression model for gap-word identification

#### For detailed instructions and findings from Korean-English lexical gap analysis, please find our paper at:
